# Smart Campus Connecté — IoT Network Simulation

A university Smart Campus network designed and simulated with Cisco Packet Tracer as part of an IoT course project.

## Project overview

The simulated campus is organized into three zones:

- **Classroom:** connected IoT devices and an automation scenario for fire detection and alerts.
- **Laboratory:** connected devices including a webcam and a carbon-dioxide detector.
- **Administration:** administrative workstations and connected services.

Each zone has local network equipment and connects through a central server area. The design demonstrates network segmentation by zone, IoT connectivity, centralized communication, and basic event-driven automation in the Packet Tracer simulation.

## Files

- `smart-campus-connected.pkt` — Cisco Packet Tracer simulation project.
- `project-report.pdf` — project report in French, including the architecture and configuration illustrations.

## How to open

1. Install Cisco Packet Tracer.
2. Open `smart-campus-connected.pkt` in Packet Tracer.
3. Inspect the network topology and IoT device configurations in the simulation.
4. Refer to `project-report.pdf` for the design description.

## Project context

Academic group project completed for the IoT module at Institut Supérieur de Gestion de Tunis during the 2025–2026 academic year.
